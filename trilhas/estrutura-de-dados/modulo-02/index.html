AULA 01 · MODELO MENTAL

O que torna uma lista “sequencial”?

No módulo anterior vimos que uma estrutura de dados organiza informações e define operações sobre elas.

Agora vamos conhecer uma maneira específica de organizar uma lista.

Lista sequencial Os elementos são armazenados em posições de um vetor.

Imagine uma estante com cinco espaços numerados:

A
índice 0
B
índice 1
C
índice 2
D
índice 3
E
índice 4

Existem cinco elementos, mas os índices vão de 0 até 4.

Se um vetor possui tamanho 5, sua última posição é 5 - 1 = 4.

Posição não é quantidade.

Esse detalhe é simples, mas aparece o tempo inteiro em programação.

Quantidade Existem 5 elementos.
Último índice O último está na posição 4.
Quantidade: 5 Índices: 0 1 2 3 4 ↓ ↓ ↓ ↓ ↓ A B C D E

Quando o código usar posição, índice ou ultimo, lembre-se dessa diferença.

MICROEXERCÍCIO

Pense antes de continuar.

Um vetor possui 8 posições. Qual é o índice da última posição?

7. Os índices seriam: 0, 1, 2, 3, 4, 5, 6 e 7.

AULA 02 · ESTRUTURA

Conheça lista_seq.

O material utiliza uma estrutura semelhante a esta: 

#define TAM 5

typedef struct lista_seq {
    char info[TAM];
    int ultimo;
} lista_seq;

Antes de olhar para isso como programação, traduza:

TAM = 5 A capacidade máxima do vetor será cinco posições.
info[TAM] É o vetor onde os elementos serão armazenados.
ultimo Guarda qual é a última posição atualmente ocupada.

O campo mais importante agora: ultimo.

Imagine uma lista com:

[ A ][ B ][ C ][ ][ ] 0 1 2 3 4 ultimo = 2

Isso significa que a última posição ocupada é a posição 2.

Não significa que existam dois elementos.

Existem 3 elementos: A, B e C.

Mas o índice do último é 2.

Como representar uma lista vazia? 

void cria(lista_seq *lista) {
    lista->ultimo = -1;
}

Se nenhuma posição do vetor está ocupada, não existe um índice válido para apontar como último.

O material usa:

ultimo = -1 [ ][ ][ ][ ][ ] 0 1 2 3 4
Regra mental ultimo == -1 → lista vazia.

E quando ela está cheia? 

int cheia(lista_seq *lista) {

    if (lista->ultimo == TAM - 1)
        return 1;

    else
        return 0;
}

Como TAM = 5, temos:

TAM - 1 5 - 1 = 4 ultimo == 4 [ A ][ B ][ C ][ D ][ E ] 0 1 2 3 4

Nesse caso todas as posições estão ocupadas.

LEITURA DE CÓDIGO

Tente ler sem decorar. 

int vazia(lista_seq *lista) {

    if (lista->ultimo == -1)
        return 1;

    else
        return 0;
}
Leia em português:

“Se a última posição for -1, retorne verdadeiro. Caso contrário, retorne falso.”
AULA 03 · INSERÇÃO

Como inserir um novo elemento?

Vamos começar com:

[ A ][ B ][ C ][ ][ ] 0 1 2 3 4 ultimo = 2

Queremos inserir D.

01 Verificar se a lista já está cheia.
02 Incrementar ultimo: de 2 para 3.
03 Armazenar D na nova posição 3.
ANTES ultimo = 2 [ A ][ B ][ C ][ ][ ] DEPOIS ultimo = 3 [ A ][ B ][ C ][ D ][ ]

Agora veja o código. 

void insere(
    lista_seq *lista,
    char info
) {

    if (cheia(lista)) {

        printf("Lista cheia!");

    } else {

        lista->ultimo++;

        lista->info[
            lista->ultimo
        ] = info;
    }
}
if (cheia(lista)) Primeiro confirme se existe espaço.
lista->ultimo++ Avance a posição do último elemento.
lista->info[lista->ultimo] = info Coloque o novo valor nessa posição.
AULA 03 · BUSCA

Buscar é acessar uma posição válida. 

char busca(
    lista_seq *lista,
    int posicao
) {

    if (
        posicao > -1 &&
        posicao <= lista->ultimo
    )

        return lista->info[posicao];
}

Observe a condição:

posicao > -1 E posicao <= ultimo

Se:

[ A ][ B ][ C ][ D ][ ] 0 1 2 3 4 ultimo = 3

são válidas:

0 1 2 3

Mas a posição 4 ainda não contém um elemento da lista, mesmo existindo fisicamente no vetor.

Essa diferença é importante:

capacidade do vetor não é a mesma coisa que quantidade de elementos usados.
PREVEJA

Sem executar o código.

[ A ][ B ][ C ][ D ][ ] ultimo = 3 busca(lista, 2)

Qual valor será retornado?

C. A posição 2 contém C.
AULA 04 · REMOÇÃO

Aqui existe uma pegadinha importante.

Começamos com:

[ A ][ B ][ C ][ D ][ E ] 0 1 2 3 4 ultimo = 4

Agora executamos: 

retira(lista, 1);

A posição 1 contém B.

Uma ideia intuitiva seria imaginar:

A B C D E remove B A C D E

Porém, não é isso que a função do material faz.

O último elemento ocupa a vaga.

01 Salve B em uma variável auxiliar.
02 Copie o último elemento E para a posição 1.
03 Diminua ultimo de 4 para 3.
04 Retorne o valor removido B.
ANTES [ A ][ B ][ C ][ D ][ E ] 0 1 2 3 4 REMOVE POSIÇÃO 1 E ocupa a vaga de B DEPOIS [ A ][ E ][ C ][ D ][ ] 0 1 2 3 4 ultimo = 3
Consequência A remoção apresentada no livro não conserva a ordem.

Por que fazer isso?

Para preservar:

A C D E

seria necessário deslocar elementos:

C → posição 1 D → posição 2 E → posição 3

O material destaca justamente que esse deslocamento teria custo computacional maior.

Leia o código em etapas. 

char retira(
    lista_seq *lista,
    int posicao
) {

    if (
        posicao > -1 &&
        posicao <= lista->ultimo
    ) {

        char aux =
            lista->info[posicao];

        if (lista->ultimo > 0)

            lista->info[posicao] =
                lista->info[
                    lista->ultimo
                ];

        lista->ultimo--;

        return aux;
    }
}
aux = info[posicao] Guarde o valor que será removido.
info[posicao] = info[ultimo] Coloque o último elemento na posição removida.
ultimo-- A lista passa a considerar uma posição a menos.
return aux Retorne o valor que foi removido.

E o imprime? 

for (
    i = 0;
    i <= lista->ultimo;
    i++
) {

    printf(
        "%c",
        lista->info[i]
    );
}

Tradução:

Comece na posição 0 e avance uma posição por vez até chegar em ultimo.
