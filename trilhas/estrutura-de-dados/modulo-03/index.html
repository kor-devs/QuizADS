MÓDULO 03 · LISTA ENCADEADA

Agora os elementos não precisam ficar lado a lado. Eles precisam saber onde está o próximo.

Você vai entender memória dinâmica, ponteiro de início, malloc, inserção, busca, remoção e liberação de memória visualizando as setas mudarem.

Aula 1 de 6 10%
AULA 01 · MODELO MENTAL

Esqueça as posições fixas.

Na lista sequencial, nossos elementos estavam dentro de um vetor:

[ A ][ B ][ C ][ D ] 0 1 2 3

Os elementos ocupavam posições sequenciais.

Na lista encadeada, os nós podem estar espalhados pela memória.

1000
nó contendo B
1250
nó contendo D
1430
nó contendo A
1530
nó contendo C

Mesmo espalhados fisicamente, conseguimos formar:

A → B → C → D → NULL
Ideia principal A ordem lógica da lista é determinada pelas ligações entre os nós, e não pela posição física deles na memória.

Como uma ligação funciona?

endereço 1430
info A
prox 1000
→
endereço 1000
info B
prox 1530
→
endereço 1530
info C
prox NULL

`prox` não contém o próximo valor.

Ele contém o endereço do próximo nó.

Quem sabe onde a lista começa?

inicio → endereço 1430
inicio │ ↓ [A] → [B] → [C] → NULL

Se sabemos onde está o primeiro nó, podemos seguir as ligações até chegar ao último.

Perdendo o endereço do primeiro nó, podemos perder o acesso à lista inteira.

AULA 02 · O NÓ

A estrutura que representa cada nó. 

typedef struct no {

    char info;
    struct no *prox;

} no;
char info; Guarda o conteúdo do nó.
struct no *prox; Guarda o endereço do próximo nó.
no Passa a ser o nome curto do tipo.

Criando uma lista vazia. 

no* cria() {

    return NULL;

}

Por que NULL?

lista = NULL Não existe primeiro nó.

Diferente da lista sequencial, não usamos:

ultimo = -1

Aqui a própria referência para o primeiro nó é nula.

Verificando se está vazia. 

int vazia(no *lista) {

    if (lista == NULL)
        return 1;

    else
        return 0;
}
Leia assim:

“Se o ponteiro que deveria apontar para o primeiro nó não aponta para nada, a lista está vazia.”
COMPARAÇÃO

Duas listas, duas formas de saber se estão vazias.

Lista sequencial ultimo == -1
Lista encadeada lista == NULL
AULA 03 · MEMÓRIA DINÂMICA

O que malloc está fazendo? 

no *novo =
    (no*) malloc(sizeof(no));

Essa linha assusta quando aparece inteira.

Vamos desmontá-la.

sizeof(no) Descubra quanto espaço um nó precisa.
malloc(...) Reserve esse espaço na memória.
no *novo Guarde o endereço desse espaço em um ponteiro chamado novo.
Modelo mental `malloc` encontra um espaço livre na memória e nos devolve seu endereço.
INSERÇÃO

O novo nó entra no início. 

no* insere(
    no *lista,
    char info
) {

    no *novo =
        (no*) malloc(sizeof(no));

    novo->info = info;

    novo->prox = lista;

    return novo;
}

Imagine:

ANTES lista ↓ [B] → [C] → [D] → NULL

Queremos inserir A.

01 Criamos um novo nó.
02 Gravamos A em novo->info.
03 Fazemos novo->prox = lista. O novo nó aponta para B.
04 Retornamos novo. Ele passa a ser o primeiro nó.
DEPOIS lista ↓ [A] → [B] → [C] → [D] → NULL

Por que esta atribuição aparece? 

lista =
    insere(lista, 'A');

Porque o endereço do primeiro nó mudou.

Antes: `lista` apontava para B.

Depois: `lista` precisa apontar para A.
PREVEJA

Qual será a ordem? 

lista = cria();

lista = insere(lista, 'D');
lista = insere(lista, 'C');
lista = insere(lista, 'B');
lista = insere(lista, 'A');
A → B → C → D → NULL

Cada novo elemento entra na frente do anterior.
AULA 04 · PERCURSO

Como visitar todos os nós?

Precisamos de um ponteiro auxiliar: 

no *aux;

Ele funciona como um marcador que percorre a lista.

lista ↓ [A] → [B] → [C] → NULL aux começa em A

Depois: 

aux = aux->prox;
lista ↓ [A] → [B] → [C] → NULL ↑ aux

E novamente:

lista ↓ [A] → [B] → [C] → NULL ↑ aux

Até:

aux = NULL

A função busca. 

no* busca(
    no *lista,
    char info
) {

    no *aux;

    for (
        aux = lista;
        aux != NULL;
        aux = aux->prox
    )

        if (
            aux->info == info
        )

            return aux;

    return NULL;
}
aux = lista Comece no primeiro nó.
aux != NULL Continue enquanto ainda existir nó.
aux = aux->prox Vá para o próximo.
aux->info == info Verifique se encontrou o valor.
return NULL Chegou ao fim sem encontrar.

Imprimir usa a mesma caminhada. 

void imprime(no *lista) {

    no *aux;

    for (
        aux = lista;
        aux != NULL;
        aux = aux->prox
    )

        printf(
            "%c\t",
            aux->info
        );
}
A lógica de percurso é praticamente a mesma.

O que muda é a ação realizada em cada nó.
AULA 05 · REMOÇÃO

Agora precisamos de dois ponteiros. 

no *ant = NULL;
no *aux = lista;
aux Aponta para o nó que estamos analisando.
ant Guarda o endereço do nó anterior.
A → B → C → D → NULL ant aux ↓ ↓ [A] → [B]

Procurando o elemento. 

while (
    aux != NULL &&
    aux->info != info
) {

    ant = aux;
    aux = aux->prox;
}

Enquanto:

ainda existir um nó E o valor ainda não for o procurado, avance os dois ponteiros.

Caso 1 — elemento não encontrado. 

if (aux == NULL)
    return lista;

Se `aux` chegou em `NULL`, percorremos tudo e não encontramos o valor.

Nada muda.

Caso 2 — remover o primeiro.

ANTES lista ↓ [A] → [B] → [C] → NULL aux = A ant = NULL
if (ant == NULL)

    lista = aux->prox;
DEPOIS lista ↓ [B] → [C] → NULL

Se `ant` ainda é `NULL`, significa que nunca avançamos.

Portanto o elemento encontrado era justamente o primeiro nó.

Caso 3 — remover no meio.

Queremos remover B A → B → C → NULL ant aux ↓ ↓ A B
ant->prox =
    aux->prox;

A ligação:

A → B

passa a ser:

A → C

B deixa de fazer parte da corrente. 

free(aux);
Só depois de corrigir as ligações liberamos a memória do nó removido.
AULA 06 · LIBERAÇÃO

Não podemos simplesmente esquecer os nós na memória. 

void libera(no *lista) {

    no *aux = lista;

    while (aux != NULL) {

        no *temp =
            aux->prox;

        free(aux);

        aux = temp;
    }
}

Existe um detalhe muito importante:

Antes de executar free(aux), salvamos onde está o próximo nó.
01 `temp = aux->prox`
salve o endereço do próximo.
02 `free(aux)`
libere o nó atual.
03 `aux = temp`
continue a partir do próximo nó.

Se fizéssemos `free(aux)` antes de guardar `aux->prox`, poderíamos perder o endereço necessário para continuar.

LEITURA DO PROGRAMA

Agora o conjunto faz sentido. 

no *list2 = cria();

list2 = insere(list2, 'D');
list2 = insere(list2, 'C');
list2 = insere(list2, 'B');
list2 = insere(list2, 'A');

imprime(list2);

list2 = retira(
    list2,
    'C'
);

imprime(list2);

libera(list2);

Resultado após as inserções:

A → B → C → D → NULL

Depois de retirar C:

A → B → D → NULL

Por que list2 = aparece tantas vezes? 

list2 =
    insere(list2, 'A');

list2 =
    retira(list2, 'A');

Porque inserir ou remover pode alterar quem é o primeiro nó.

A variável que guarda o início da lista precisa receber o endereço atualizado.
BÔNUS · OLHANDO ADIANTE

E se quisermos inserir em ordem?

O material também apresenta uma extensão que usa dois ponteiros: 

ant = NULL;
aux = lista;

while (
    aux != NULL &&
    aux->info < info
) {

    ant = aux;
    aux = aux->prox;
}

O raciocínio é o mesmo que acabamos de aprender:

ant → nó anterior aux → nó posterior novo entra entre os dois
Você não precisa decorar essa função agora.

O importante é perceber que `ant` + `aux` formam uma técnica para manipular ligações entre nós.
