Aula 1 de 5 20%
AULA 01

O que é uma estrutura de dados?

Antes de pensar em código, pense no problema que o computador precisa resolver.

Dados podem existir de muitas formas: nomes de clientes, produtos, compromissos, notas de alunos, transações ou milhares de registros.

Se simplesmente jogássemos todas essas informações na memória sem nenhuma organização, trabalhar com elas seria difícil e ineficiente.

Estrutura de dados É uma forma organizada de armazenar dados e definir como podemos trabalhar com eles.
Dados São as informações que queremos guardar.
Organização Define como esses dados ficam relacionados.
Operações Definem o que conseguimos fazer: inserir, buscar, remover etc.
Objetivo Resolver um problema de forma organizada e eficiente.

Um exemplo sem programação

Imagine uma agenda de contatos.

Cada contato possui dados:

Nome: Ana Telefone: 11 99999-9999 Email: ana@email.com

Mas apenas guardar esses dados não basta. Também precisamos realizar operações:

Adicionar contato Buscar contato Alterar contato Remover contato Listar contatos

Essa combinação entre dados organizados e operações será muito importante daqui para frente.

AULA 02

Entendendo TAD

TAD significa Tipo Abstrato de Dados .

O nome parece complicado, mas a ideia é simples.

TAD = dados + operações Primeiro definimos o que a estrutura guarda. Depois definimos quais ações podem ser realizadas sobre esses dados.

Pense em uma conta bancária.

Dados Saldo, titular, número da conta.
Operações Depositar, sacar, consultar saldo.

Você não precisa saber como o banco grava fisicamente cada informação para utilizar uma conta.

Essa separação é a ideia de abstração: conseguimos trabalhar com algo sem precisar conhecer todos os detalhes internos ao mesmo tempo.

TAD no nosso livro

Ao estudar listas, pilhas, filas e árvores, veremos sempre a mesma lógica:

ESTRUTURA ↓ DADOS + OPERAÇÕES

Por exemplo, uma lista pode possuir operações como:

cria() insere() busca() retira() imprime() libera()

Não tente decorar esses nomes agora. Entenda apenas o padrão:

Pergunta importante “O que essa estrutura guarda e o que podemos fazer com ela?”
AULA 03

Nó, memória e endereço

Agora chegamos em um dos pontos que costuma causar confusão: ponteiros.

Antes de falar de ponteiro, precisamos falar de memória.

Pense na memória como vários locais numerados. Cada informação armazenada ocupa algum local, e esse local possui um endereço.
MEMÓRIA Endereço 1000 → "Ana" Endereço 1001 → 27 Endereço 1002 → 9.5 Endereço 1003 → ...

Na prática os endereços são muito mais complexos, mas para aprender estrutura de dados podemos pensar dessa forma.

O que é um nó?

Em estruturas encadeadas, os dados normalmente são organizados em pequenas estruturas chamadas nós.

┌──────────────────────┐ │ NÓ │ ├──────────┬───────────┤ │ info │ prox │ ├──────────┼───────────┤ │ A │ endereço │ └──────────┴───────────┘

Observe que esse nó guarda duas coisas.

info É o dado armazenado.
prox Guarda o endereço do próximo nó.

Isso permite ligar vários nós:

┌─────┬──────┐ │ A │ ─────────┐ └─────┴──────┘ │ ↓ ┌─────┬──────┐ │ B │ ─────────┐ └─────┴──────┘ │ ↓ ┌─────┬──────┐ │ C │ NULL │ └─────┴──────┘

O nó A sabe onde B está. B sabe onde C está.

C possui NULL porque não existe próximo nó.

Então o que é um ponteiro?

Ponteiro é uma variável que guarda um endereço de memória.

Ele não precisa guardar o dado diretamente.

Ele pode guardar onde o dado está.

ponteiro inicio │ │ endereço 1000 ↓ ┌────────────┐ │ Nó A │ │ endereço │ │ 1000 │ └────────────┘

Essa é uma ideia fundamental.

Quando encontrar a palavra ponteiro, pense:

“Uma variável que sabe o endereço de outra coisa.”
AULA 04

Agora o código começa a fazer sentido.

Observe esta estrutura usada no material: 

typedef struct no {
    char info;
    struct no *prox;
} no;

Não leia isso como um bloco misterioso. Vamos traduzir.

struct no = estamos descrevendo um tipo de estrutura chamado nó.
char info; = dentro do nó existe um campo chamado info.
struct no *prox; = dentro do nó existe um ponteiro chamado prox que pode guardar o endereço de outro nó.
typedef ... no; = estamos criando uma forma mais curta de chamar essa estrutura.

O que significa o asterisco? 

struct no *prox;

Nesse contexto, o * indica que prox é um ponteiro.

Ou seja:

prox não guarda outro nó inteiro. Ele guarda o endereço de outro nó.

E essa seta? 

novo->info = 'A';

novo->prox = lista;

O operador -> é usado quando temos um ponteiro apontando para uma estrutura e queremos acessar um campo dela.

novo->info = acesse o campo info do nó apontado por novo.
novo->prox = acesse o campo prox do nó apontado por novo.

NULL 

novo->prox = NULL;

NULL significa que aquele ponteiro não está apontando para um endereço válido de outro nó.

A → B → C → NULL

Nesse desenho, NULL indica:

“C não possui próximo elemento.”
